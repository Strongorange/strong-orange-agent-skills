# dev-pc-memory-audit

실측 → 보고 · 선택 → 적용 → 같은 방법으로 재측정 → 이 PC 기록 문서에 남김. 이 순서를 바꾸지 말 것. 실제로 한 PC 를 정리한 사례(세션 5개에 MCP 7GB, vmmemWSL 19.6GB)를 일반화한 것이라, 항목과 숫자는 예시이고 대상 PC 에서 다시 재야 함.

## 원칙

- 재기 전에 고치지 말 것. 추측한 원인은 측정으로 확인한 뒤에만 보고에 씀.
- 사용자가 쓰는 앱은 크더라도 끄지 말 것. 각 항목을 "쓰는지" 사용자에게 물음. 백신 · 회사 보안 에이전트는 묻지 않고 그대로 둠.
- 팀 · 회사가 함께 쓰는 설정(팀 레포, 팀 sync 스크립트가 등록하는 MCP)은 이 PC 에서만 바꿀 수 있는지 먼저 확인. 안 되면 팀원 기본 동작이 그대로인 옵트인 변경으로 PR 을 제안.
- 바꾸기 전 설정 파일은 날짜를 붙여 백업. 비밀값이 든 백업 · 환경 파일은 권한 600.
- "세션마다 늘어나는 비용"과 "한 번만 드는 비용"을 나눠 보고. 세션을 많이 띄우는 사람에겐 앞쪽이 훨씬 큼.

## 절차

### 1. 실측

명령은 [references/measure.md](references/measure.md). 최소한 다음을 잴 것.

- OS 전체 사용량, 앱별 합계(프로세스 이름으로 묶어 Private · Working Set)
- WSL: `free -m`(used 와 buff/cache 따로), 프로세스 이름별 합계, `vmmemWSL` 크기
- 에이전트 세션 수와 세션마다 딸린 자식 프로세스(MCP · LSP)를 종류별 개수 · 합계로
- WebView2 처럼 이름만 봐선 주인을 모르는 프로세스는 부모를 따라가 주인 앱으로 묶음

### 2. 보고 · 선택

[references/checks.md](references/checks.md) 의 항목을 측정 결과에 대 보고 걸린 것만 표로 보고. 열: 항목 · 지금(개수 · MB) · 방법 · 줄어드는 양(지금 세션 수 기준) · 주의. 그다음 사용자가 고를 것을 번호로 묻고 멈춤.

### 3. 적용

- 고른 것만 적용. 한 항목씩 백업 → 변경 → 그 항목 검증 순서.
- 에이전트 설정은 가능하면 공식 CLI(`claude mcp add/remove`, `claude plugin disable`)로 바꿈. 에이전트가 돌면서 설정 파일을 다시 쓰므로 손 편집은 덮일 수 있음.
- 지금 떠 있는 세션은 시작할 때 읽은 설정으로 계속 돎. 효과는 새 세션부터라는 점을 보고에 적을 것.

### 4. 검증

- 바꾼 MCP: `claude mcp list` 의 연결 상태 + 새 세션을 띄워 자식 프로세스가 0개인지(1초 간격으로 확인).
- 바꾼 LSP: 새 세션에서 hover 같은 LSP 호출 한 번.
- 공용 서버로 바꾼 것: 실제 도구 호출 한 번 + [references/checks.md](references/checks.md) 의 보안 점검.
- 수치는 1단계와 같은 명령으로 다시 재서 전 · 후 표로. 1회 측정은 "1회 관찰" 로 적음.

### 5. 기록

이 PC 에서만 쓰는 설정 기록 문서에 남길 것: 무엇을 왜 바꿨는지, 되돌리는 명령, 서비스 이름 · 포트 · 백업 경로, 손으로 띄운 것. 에이전트 메모리는 프로젝트마다 따로라 다른 곳에서 안 보이므로 쓰지 말 것. 권장 위치는 `~/.agents/skills/local-pc-setup/SKILL.md` 같은 이 PC 전용 스킬(공개 레포에 올리지 않음).

## 함정

- `systemctl --user` 가 WSL 에서 `Failed to connect to bus` 로 실패할 수 있음. WSLg 가 `/run/user/<uid>` 를 덮어서 생김. 서비스 파일 · `default.target.wants` 링크는 직접 만들면 재부팅 때 적용됨. 그때까지는 손으로 띄우고 기록에 적을 것.
- systemd `ExecStart` 는 절대경로. `Environment=PATH` 로 실행 파일을 찾지 않아 `203/EXEC` 로 실패함.
- 설정 파일을 출력해 확인할 때 API 키 · 비밀번호를 가린 뒤 출력할 것. 가리는 정규식이 키 이름을 놓치면 그대로 화면에 나옴.
- 같은 PC 에 다른 에이전트 세션이 떠 있으면 "가장 최근 수정된 파일"로 세션을 고르는 스크립트가 남의 세션을 집음.
